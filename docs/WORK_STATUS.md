## v74.5 변경 범위

- GPS 수신, 차량정보 대조, 서버 전송 대기를 구분한다. 예정시각 이후 차량 대조 불가를 출발대기 0%로 확정하지 않는다. 정상 GPS 속도는 계속 표시한다.
- 자동 위치 갱신 실패 시 이전 앞차·뒷차·차량 대조 값을 지우고 연결 실패를 표시한다. 계정·날짜·배차·차량 변경 후 늦게 도착한 응답은 폐기한다.
- 출발 판정 로직은 변경하지 않는다. 외부 API 장애 해결, 누락 시각 복구, API 없는 자동 출발은 이번 변경의 완료 범위에 포함하지 않는다.
- 이 변경은 웹에만 적용된다. 서버 및 Android 실행 코드는 동일하며 기존 APK v74와 호환된다.
- 합성 검증: GPS 정상/API 실패, 출발 전 대기, 과거·완료 화면, 오래된 차량정보, 전송 대기, 백그라운드 오류, 계정·차량 전환. 브라우저 검증은 320/360/412px 화면을 사용한다. 실 API·실기기 검증과 구별한다.

## 남은 기술 작업

- 실시간 API 실제 HTTP/제공기관 응답코드와 계정 사용량 확인. 공식 기본 한도만으로 한도 초과를 확정하지 않는다.
- API 대조가 끊긴 상태에서 자동 출발이 차단되는 동작 및 통신 복구 후 판정 재개 검토.
- PR40 서버 변경·배포·권한 검증 후 웹 반영. 최신 main의 v74.5 변경을 보존하고 후속 버전을 사용한다. PR41의 성공을 PR40 배포 완료로 사용하지 않는다.
- 실제 모바일 및 현장 검증. ChatGPT 대화 동기화 자체를 변경한 것은 아니다.

## v75 휴무 표시·앱 아이콘 준비

- 기사 인증 조회에서 휴무계획·관리자 승인 변경·조별 근무 기준을 대조한다. 지정휴무, 승인휴무 기간, 조별 비번과 미확정 배차를 구분한다. 월별 휴무는 펼쳐서 확인한다.
- 신청 대기·반려·취소를 승인휴무로 사용하지 않는다. 확정 배차와 휴무가 겹치면 배차를 보존하고 확인 안내를 표시한다. 날짜/기사별 조회 범위를 유지하며 휴무 원장을 수정하지 않는다.
- 기본 Android 아이콘을 새 버스 캐릭터로 교체한다. 앱 ID와 서명 설정 유지, versionCode 75 / versionName 0.75-leave-icon. 웹 아이콘·캐시 버전도 갱신한다.
- 코드 검증과 실제 배포는 구별한다. Apps Script의 AuthStep9 갱신 및 기존 웹앱 새 버전 배포가 필요하다. APK 설치만으로 서버 휴무 기능이 반영되지는 않는다.
- 준비 검증: 지정/신청 승인 기간, 대기/취소, 타 기사 분리, 월 경계, 조별 예외, 배차 충돌, KST 날짜/세션 복구 및 기존 출발 판정.
- 아이콘은 내장 이미지 생성 도구로 제작: 귀엽고 고급스러운 애니메이션 버스, 남색·에메랄드·금색 포인트, 글자 없음. 앱 자산 icons/bus70-512.png.
