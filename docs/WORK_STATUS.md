# 공통 작업현황

확인 기준: 2026-10-15 20:05 KST. 아래는 이 시점의 확인 기록이다. 이후 작업은 원격 저장소·배포·비공개 원장을 다시 조회한다.

## 준비 중: 소장·마스터 접속·트래픽 v74.4

- 소장·마스터 업무 홈에 `접속·트래픽`을 추가한다. 서버에서 권한 확인 후 유효한 기사 로그인 세션을 기사별로 묶고 이름·노선·근무조·세션 수·최근 통신 시각을 제공한다. 기사·정비소·비로그인 요청에는 접속자 정보를 반환하지 않는다.
- 로그인 유지와 최근 3분 통신을 구분한다. 앱 또는 GPS 서비스 통신이 확인되어도 실제 차량 운행 중이라는 뜻은 아니다. 과거 세션에 관측 시각이 없거나 캐시가 소실되면 `최근 통신 미확인`으로 표시한다. 로그아웃·만료 세션은 제외한다.
- 기존 인증 요청에 수집기를 붙여 최근 5분·60분의 수집 요청 수, 오류·거절 수, 평균 서버 처리시간을 표시한다. 인증정보·요청 본문·GPS 좌표는 집계에 저장하지 않는다. 캐시는 60분으로 제한하며 수집기 실패는 원래 작업을 실패시키지 않는다.
- 집계는 캐시 기반 참고값이다. 서버에 미도달한 통신, 전체 전송량·Google 할당량은 알 수 없다. 잠금 경합 시 추가 대기를 만들지 않고 누락 가능 상태를 표시한다. 캐시가 비어 있으면 0으로 확정하지 않고 수집 대기로 표시한다.
- 화면이 보일 때만 1분 간격으로 갱신한다. 일반 요청이 최근에 있으면 추가 상태 확인을 생략한다. 조회 실패 시 오래된 접속자와 숫자를 지우고 확인 불가 상태를 표시한다. 계정 변경 후 늦게 도착한 결과는 폐기한다.
- 상태: 코드·합성 테스트 준비. 운영 서버 배포 및 웹 릴리스는 **아직 완료되지 않음**. Google Apps Script 편집 화면은 재로그인이 필요하며 이 환경의 공개 ping 확인도 브라우저 접근 오류로 완료하지 못했다. 이 사실을 사용자 휴대폰 오류의 원인으로 단정하지 않는다. 서버 로그인 복구 후 기존 배포를 갱신하고 응답·권한을 확인한 뒤 PR을 병합한다. APK v74는 그대로 사용할 수 있는 웹·서버 변경이다.

## 후속 변경: 기사 날짜·시간 선택 v74.3

- 기본 조회일은 한국시간 오늘이고, 날짜 선택 즉시 해당 스케줄을 불러온다. `운행정보 조회`와 `오늘 스케줄` 상시 버튼을 제거한다. 선택한 날짜가 오늘이면 자동 날짜 전환 모드로 복귀한다.
- 날짜와 시간 표시 선택을 한 줄에 배치하고 시간 표시 칸은 108px로 줄인다. 시간 표시 변경은 화면만 다시 그리며 서버를 재조회하지 않는다.
- 오늘 스케줄이 없으면 `?` 표시를 유지한다. 조회 실패 때는 해당 오류 영역에만 재시도 버튼을 제공한다.
- 날짜 경계·복귀·늦은 응답·세션 복구 검증과 모바일 컨트롤 배치 검증은 `Driver mobile layout` CI에서 확인한다. 배포 결과는 최신 Actions와 비공개 작업연계DB 후속 이력을 확인한다. 서버63·전달 APK v74는 유지한다.

## 남은 작업과 한계

- 새 도메인 연결은 완료되지 않았다. DNS·HTTPS·Android 허용 호스트/시작 주소·기존 사용자 접근을 함께 확인한 뒤 전환해야 한다. 구매 확인과 서비스 연결 완료를 구분한다.
- 서버·DB 이전 구조는 논의 단계다. PostgreSQL 이전, Cloudflare 연결, 새 호스팅 구축이 완료됐다고 간주하지 않는다.
- 이번 승계 절차는 작업 기록과 확인 책임을 명확히 한다. ChatGPT 계정 자체의 동기화 기능을 변경하지 않으며, 모든 대화에 이 파일이 자동으로 로드되거나 서로 다른 세션의 편집이 자동 잠금된다는 보장은 없다.
- 기기를 옮긴 뒤에는 `AGENTS.md`와 이 문서를 읽고 해당 연결 원본에 접근 가능한지 확인한다. 접근 불가 항목은 그 범위만 명시하고 가능한 작업을 계속한다.
