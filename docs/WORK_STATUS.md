## 남은 작업과 한계

- 새 도메인 연결은 완료되지 않았다. DNS·HTTPS·Android 허용 호스트/시작 주소·기존 사용자 접근을 함께 확인한 뒤 전환해야 한다. 구매 확인과 서비스 연결 완료를 구분한다.
- 서버·DB 이전 구조는 논의 단계다. PostgreSQL 이전, Cloudflare 연결, 새 호스팅 구축이 완료됐다고 간주하지 않는다.
- 이번 승계 절차는 작업 기록과 확인 책임을 명확히 한다. ChatGPT 계정 자체의 동기화 기능을 변경하지 않으며, 모든 대화에 이 파일이 자동으로 로드되거나 서로 다른 세션의 편집이 자동 잠금된다는 보장은 없다.
- 기기를 옮긴 뒤에는 `AGENTS.md`와 이 문서를 읽고 해당 연결 원본에 접근 가능한지 확인한다. 접근 불가 항목은 그 범위만 명시하고 가능한 작업을 계속한다.
