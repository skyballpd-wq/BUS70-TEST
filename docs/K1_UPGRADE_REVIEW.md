2026-11-14 기준으로 접근 가능한 이전 요청, 작업 승계 기록, 원격 main, 열린 PR, 현재 소스와 자동검사를 대조했다. 프로젝트 내 모든 채팅의 전체 원문과 전체 목록을 제공하는 인터페이스는 확보하지 못했다. 대화 검색에서 누락된 요구가 있을 수 있다.

## 구조 개선 순서

1. 실제 운행 기록·음성·재전송의 일관성과 세션 전환을 먼저 검증한다.
2. 예비 배치를 기사 유형 및 근무조와 분리하고, 기존 가입·근태·대체·재입사를 통해 저장된 자료도 호환한다.
3. 정비 예상 완료와 다음 확정 배차를 연결하고 지연 안내·확인 이력을 연계한다.
4. 접속·트래픽 현황을 현행 서버에 통합해 요청량과 응답시간을 측정한다. 측정값으로 공유 조회 및 저장 경로의 병목을 개선한다.
5. 대규모 동시접속 검증과 운영 DB 이전은 측정 결과와 실제 배포 환경을 기준으로 진행한다.

검증에는 합성 기사·차량·운행 자료만 사용한다. 실제 기록의 누락 시각, 실제 정비 완료, 실기기 설치 성공은 자동검사에서 생성하지 않는다.
