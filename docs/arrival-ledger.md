# 운행 원장 표와 정류장별 조기 도착 안내

## 원장 형식
기존 운행일지 원장을 기준으로 운행일·기사·노선·차량·순차·탕, 출발지/예정/실제, 회차지/예정/실제, 도착지/예정/실제를 같은 항목 순서로 조회한다. 앱 원장 표와 XLSX는 `Bus70Ledger.headers/rows`를 공유한다. 모바일에서는 동일한 값의 지점별 작은 표도 제공한다. 현장 종이 원본이 제공되면 세부 칸 배치를 대조한다.

실제 도착·영업종료·차고지 복귀 시각은 빨간색이다. 영업종료와 별도 회송 복귀는 합치지 않는다. 실제 시각이 없으면 빈칸/미기록을 유지하며 계획이나 예측을 실제 시각으로 저장하지 않는다. 서버 저장 대기 중인 기기 시각은 별도로 표시한다. XLSX는 수식으로 실행되지 않는 텍스트 셀이며 자정 이후에는 다음날을 표시한다. 원본 시각과 저장 정밀도를 변경하지 않는다.

Android 78의 엑셀 저장은 시스템 파일 저장 화면을 사용한다. 추가 저장소 접근 권한은 요구하지 않는다.

## 경고 구간과 조건
고강차고지가 해당 탕의 예정 도착지이고 실제 출발이 확인된 완료 전 운행에만 적용한다. 하행 역곡역북부의 GBIS 정류장 식별값 `210000307`을 노선 순서에서 찾아 통과 여부를 판정한다. 동명 상행 정류장 `210000298`이나 정류장 이름만으로 경고를 시작하지 않는다. 순서 번호를 고정하지 않는다. 해당 기준점이 없는 노선에서는 경고하지 않는다.

하행 역곡역을 지난 뒤 고강차고지 전까지 각 정류장 도착 시 평가한다. 순서와 위치가 함께 맞고 50m 이내의 새 GPS가 1.5초 이상 이어져야 도착 확인이 된다. 같은 정류장에서 안내가 접수되면 화면 재개·서비스 재시작 때 반복하지 않으며 다음 정류장에서 새로 평가한다. 정류장 사이와 차고지 80m 이내에서는 안내하지 않는다. 안내 횟수 제한이나 5km 제한을 적용하지 않는다.

최근 10초 이내 정확도 40m 이하 GPS로, 최근 2~5분과 최근 1분의 노선 이동·정차 평균 중 느린 값을 사용한다. 2분 또는 예상 소요시간 25% 중 큰 여유를 더한 도착 추정도 계획보다 10분 이상 빠르면 음성을 요청한다. GPS 단절·점프·긴 정차·상하행 미확인·출발 전·완료·별도 회송 종점은 제외한다. 근거가 부족하면 추정/경고를 유보하며 실제 기록은 변경하지 않는다.

위치 서비스가 동작하는 동안 배경에서도 평가하고 기존 음성 설정을 존중한다. 안내 문구는 “차고지에 예정 시각보다 10분 이상 일찍 도착할 것으로 예상됩니다. 배차 시간을 확인하고 안전하게 운행하세요.”이다. 전체화면 알람을 생성하지 않는다. 음성 엔진이 준비되지 않은 경우 같은 정류장 안에서 5초 간격으로 요청을 재시도한다.
