# 경기버스 위치 API 한도 확장 및 GPS 보조

## 먼저 확인할 사항

대상 API는 공공데이터포털의 경기도_버스위치정보 조회(15080648)다. routeId 하나로 해당 노선 차량 목록을 조회한다. 현재 계정의 승인 한도·실사용량·야간 오류 원문은 계정에서 확인해야 하며, 미수신만으로 일일 한도 소진을 확정하지 않는다. 인증키·원본 인증 응답은 공개 저장소나 화면에 남기지 않는다.

## 계정에서 진행하는 절차

1. 현재 플랫폼에 사용하는 인증키의 공공데이터포털 계정으로 로그인한다.
2. 마이페이지 > 데이터 활용 > OPEN API > 활용신청 현황에서 **경기도_버스위치정보 조회**를 선택한다.
3. 승인된 계정 유형, 일일 트래픽, 사용량, 활용기간과 상세 변경신청 항목을 확인한다. 개발계정이면 실제 서비스 활용사례를 첨부하여 운영계정을 신청하고, 운영계정이면 트래픽 증량/변경신청을 진행한다. 메뉴·처리는 데이터 제공기관에 따라 달라질 수 있다.
4. 최초 검토 요청량은 **하루 10,000회**로 제안한다. 3개 노선을 서버에서 45초 간격으로 하루 20시간 조회하면 4,800회(24시간이면 5,760회)이며 재시도·검증 여유를 더한 값이다. 이 수치는 실제 승인 한도나 실측 사용량이 아니다.
5. 활용 목적, 실제 기존 웹주소, 개인 식별정보를 가린 화면, 중앙 수집/캐시 구조와 요청량 산식을 첨부한다. 새 도메인은 실제 연결 전에는 예정 주소로만 기재한다.
6. 승인 후 한도/적용일/활용기간/키 변경 여부를 확인한다. 키가 바뀌면 서버 비공개 설정에만 반영한다. 야간 실제 오류·요청량과 회복 여부를 재확인한다.

변경 메뉴가 없거나 위치 API의 증량 조건이 불명확하면 경기도 교통정보과 031-8008-6832에 해당 API명을 지정하여 문의한다. 신청 제출이나 담당자 연락은 아직 수행하지 않았다.

### 신청 사유 초안

소신여객 운행 지원 플랫폼에서 5·23·70번 노선의 앞뒤 차량 위치와 간격을 제공합니다. 노선별 중앙 조회 결과를 기사/관리 화면이 공유하며, 기사 수만큼 외부 API를 중복 호출하지 않도록 운영할 계획입니다. 3개 노선 × 하루 20시간 × 시간당 80회(45초 간격) = 4,800회와 재시도·검증 여유를 고려하여 하루 10,000회를 요청합니다. 개인정보는 외부 공개하지 않으며, 위치 미수신 시 최신성이 확인되는 운행 기사 GPS 자료만 보조로 사용합니다.

## 요청량을 줄이는 방식

- 동일 API 키를 사용하는 모든 앱의 합산 사용량을 확인한다.
- 동일 노선/조회주기의 서버 캐시와 동시 요청 잠금으로 중복 호출을 억제한다. 캐시가 만료되기 전 새로고침을 반복해도 외부 호출 수가 늘지 않아야 한다.
- 운행 중인 노선만 수집하고 오류 종류에 따른 재시도 간격을 둔다. 일일 제한과 순간 호출 제한을 구분한다.
- 추가 인증키를 무작정 만들어 제한을 우회하지 않는다. 별도 API인 정류소/도착/날씨의 한도와 서버 자체 한도도 따로 측정한다.
- Cloudflare에 주소를 연결하는 것만으로 공급 API 승인량이 늘어나지는 않는다.

## 이번 웹 GPS 보조 수정

인증·배차에 묶인 기사 휴대폰 GPS를 기존 서버로 수신한다. 45초를 넘은 다른 차량 위치는 현재 간격 계산에서 제외하되, 이미 수집한 통과 이력은 최대 90초의 수신 공백을 견디게 한다. 같은 차량·배차·탕·운행일·방향으로 다시 수신되면 이력을 이어 쓴다. 90초 초과, 낮은 정확도, 차량/탕/방향 변경, 역방향 이동은 연속성을 끊는다. 정류장을 건너뛰면 중간 통과시간을 만들지 않는다.

시간 간격은 두 차량의 같은 정류장 통과 관측 구간이 있을 때만 근삿값으로 표시한다. 내 차 GPS만으로 수신되지 않는 앞뒤차 위치를 알아낼 수 없다. 이 수정은 외부 API 호출을 추가하지 않으며 수신하지 않은 차량을 GPS 공유 차량처럼 표시하지 않는다.
